# Shorts Research Lab

YouTube Shortsをジャンル横断で分析し、「人がなぜ見続けるのか」を再利用できる制作知識に変える研究リポジトリ。

> **目的**：動画の表面だけを真似ず、視聴者の注意が続く構成・演出・情報の運び方を検証して、実際のAI動画制作へ反映する。

## 最初に読む

- [分析方法・証拠の扱い](docs/METHOD.md)：見たことと推測を混同しない
- [視聴を引き込む構成パターン](docs/PATTERNS.md)：刺激型、発見型、物語型、挑戦型、コント、変化過程型など
- [横断比較と次の検証](research/COMPARISON.md)
- [動画制作チェックリスト](docs/PRODUCTION_CHECKLIST.md)

**調査上の重要な制限**：初回7本はウェブから取得した本文・字幕等を根拠に構成を分析した。動画の全フレームや編集テンポを直接検証したわけではない。再生数・カット頻度・音の使い方などの断定には別途映像確認が必要。

## ジャンルと構成は別のもの

科学解説でも高速・強刺激型にできるし、ゲーム動画でもゆっくりした物語型にできる。ジャンル（題材）と構成（引き込み方）を別の軸で分類する。

## 次の進め方

1. [候補一覧](research/BACKLOG.md)から異なるジャンルの実例を選ぶ。
2. 取得できた根拠（動画視聴／字幕／メタデータ）を記録する。
3. 「最初の約3秒→途中の変化→最後の報酬」を分析する。実際の秒数は見ていない限り推定しない。
4. 同じ型を新しいテーマで試し、[制作チェックリスト](docs/PRODUCTION_CHECKLIST.md)で検証する。
5. 公開後の視聴データが取れれば、仮説と実績を照合する。

動画の再配布や字幕全文の保存はしない。リンクと独自の要約・分析を保存する。
