# 視聴を引き込む構成パターン

「ドパガキ向け」などは作り手の便宜的な呼称であり、視聴者を一括りにした科学的分類ではない。題材ではなく、どの種類の期待が次の瞬間へつながるかを分類する。

| パターン | 最初の興味 | 中盤で起こすこと | 終盤の報酬 | 失敗例 |
|---|---|---|---|---|
| **刺激・高速展開型** | 強い画・音・意外な一言 | 変化／対比／小さな驚きが続く | 大きなリアクション・衝撃・笑い | 音がうるさいだけ、意味が追えない |
| **発見・問題連鎖型** | 身近な疑問 | 問題→試行→次の問題を繰り返す | 仕組みが腑に落ちる | 数字や用語の羅列で「だから？」となる |
| **挑戦・結果待ち型** | 成功条件を提示 | 失敗／工夫／再挑戦／制約 | 成否や意外な達成方法 | 結果が早く見える、過程が冗長 |
| **コント・ズレ拡大型** | 常識から少し外れた設定 | ズレが拡大し、登場人物が真剣に対応 | オチ／状況の逆転 | 前提が伝わる前にネタが進む |
| **修復・変化過程型** | ひどい初期状態 | 汚れ・欠損が工程で改善 | 完成品の比較・満足感 | 途中が省略され過ぎ、変化に納得できない |
| **情報凝縮・総集編型** | 「これだけで分かる」約束 | 複数の因果・情報を高速に接続 | 全体像の獲得 | 予備知識がない人が脱落 |
| **秘密・新発見型** | 自分が知らない「裏側」 | 出典／手がかり／現場確認 | 秘密の正体・想定外の発見 | 釣りタイトル、根拠不足 |
| **参加・クイズ型** | 即答を要求 | 問題・カウント・難易度変化 | 正答・自己評価・参加感 | 答えが読めない、早過ぎる |
| **物語・感情型** | 不安／共感／人間関係 | 困難・誤解・選択・心情変化 | 解決・逆転・余韻 | 不自然な感動誘導 |

## 組み合わせの例
- **刺激×発見**：最初の一秒に現象を見せ、途中は因果を丁寧につなぐ。
- **挑戦×コント**：無謀な目標と予想外の失敗で興味を継続させる。
- **修復×物語**：単なるビフォーアフターではなく、物が持つ由来に意味を与える。
- **情報凝縮×秘密**：圧縮し過ぎると理解できなくなるため、最小限の手がかりを残す。

## 制作に転用する際の原則
- フックは**大きな文字**ではなく、疑問・予測・未解決の約束を作ること。
- 無音や静止が常に悪いわけではない。見ている人が考えたり期待したりできる間なら有効。
- 映像は「説明している対象」または「場面の変化」を示すこと。装飾目的の無関係な素材は逆効果。
- 動画の最後に何が得られるかを企画時に決める。
- パターンの善し悪しは視聴者層とテーマ次第。自作動画で実測して更新する。
